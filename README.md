# ML-fundamental-knowledge & Python Learning


A collection of Python programming exercises, learning notes, and machine learning coursework completed during my Statistics studies at UNSW.

This repository documents my progress in developing practical programming, statistical modelling, and machine learning skills.

## Repository Contents

### 1. Basics of Python Programming
**File:** `Basics of Python Programming.ipynb`

Introductory Python programming exercises and personal learning notes, documenting my understanding of fundamental programming concepts.

### 2. Linear Regression on the Diabetes Dataset
**File:** `Linear Regression on the Diabetes Dataset.ipynb`

A coursework notebook exploring linear regression using the Diabetes dataset, with programming exercises and personal notes on statistical modelling.

### 3. Abalone Neural Network Analysis
**File:** `abalone-neural-network-analysis.ipynb`

A structured machine learning coursework project using the Abalone dataset.

Key topics include:
- Data preprocessing and feature engineering
- Neural network architectures and hidden-layer configurations
- SGD and Adam optimisation
- Comparison with logistic regression
- Model evaluation and performance analysis

- **Programming:** Python
- **Libraries:** NumPy, Pandas, Scikit-learn
- **Environment:** Jupyter Notebook
